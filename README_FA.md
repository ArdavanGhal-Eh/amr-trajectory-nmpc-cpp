## 📌 طرح مسئله و انگیزه مهندسی

در انبارهای هوشمند رباتیک و کارخانجات صنعتی (نظیر آمازون رباتیکس و خطوط تسلا)، ربات‌های AMR نیازمند تعقیب مسیرهای اسپیلاین پیچیده در راهروهای باریک هستند در حالی که با موانع پیش‌بینی‌نشده، انسان‌ها و سایر ربات‌ها مواجه می‌شوند:
1. **کوپلینگ غیرخطی کینماتیک دیفرانسیلی:** معادلات حرکتی ربات دیفرانسیلی به دلیل جملات مثلثاتی ($\dot{x} = v \cos\theta, \dot{y} = v \sin\theta$) شدیداً غیرخطی و غیرهولونومیک هستند. کنترل‌کننده‌های خطی کلاسیک (نظیر PID و تعقیب محض) در سرعت‌های بالا دچار انحراف شدید از مسیر می‌شوند.
2. **برخورد با موانع دینامیک:** روش‌های واکنشی ساده (میدان پتانسیل) در راهروها در تله‌های مینیمم محلی گرفتار شده یا دچار نوسان شدید فرمان می‌شوند.
3. **بودجه زمانی زیر یک میلی‌ثانیه:** کامپیوترهای صنعتی نیازمند ارسال فرامین به درایورهای موتور در فرکانس ۱۰۰ تا ۲۰۰ هرتز هستند ($< 1\text{ ms}$). حل‌کننده‌های سنگین تجاری به دلیل جهش‌های تاخیر زمانی مناسب این محیط‌ها نیستند.

این پروژه یک حل‌کننده NMPC اختصاصی و فوق‌سریع در **C++20** ارائه می‌دهد که میانگین زمان حل آن **کمتر از ۲۵۰ میکروثانیه** است.

## ✨ ویژگی‌ها و توانمندی‌های کلیدی

- ⏱️ **حل فوق‌سریع زیر ۳۰۰ میکروثانیه (`< 300 µs`):** الگوریتم نزول گرادیانی مبتنی بر مشتقات تحلیلی بدون وابستگی به حل‌کننده‌های سنگین بیرونی.
- 📐 **انتگرال‌گیری رانگ-کوتا مرتبه چهارم (RK4):** شبیه‌سازی پیش‌بین دقیق حالات ربات در افق پیش‌بین ($N=15$ گام).
- 🛡️ **توابع مانع نرم لگاریتمی (Barrier Functions):** جریمه نزدیک شدن به موانع متحرک با گرادیان‌های پیوسته که از پرش ناگهانی زاویه فرمان جلوگیری می‌کند.
- 🚦 **اعمال قیود سخت اشباع محرک‌ها:** محدودسازی کران سرعت خطی ($v \in [0, v_{\max}]$)، سرعت زاویه‌ای ($\omega$) و نرخ شتاب چرخ‌ها.

## 📐 فرمولاسیون ریاضی کنترل پیش‌بین NMPC

### مدل کینماتیکی ربات دیفرانسیلی
$$\dot{\mathbf{x}} = \begin{bmatrix} \dot{x} \\ \dot{y} \\ \dot{\theta} \end{bmatrix} = \begin{bmatrix} v \cos\theta \\ v \sin\theta \\ \omega \end{bmatrix}$$

انتگرال‌گیری عددی حالات در طول افق پیش‌بین با روش RK4:
$$\mathbf{x}_{k+1} = \mathbf{x}_k + \frac{\Delta t}{6} (k_1 + 2k_2 + 2k_3 + k_4)$$

### تابع هزینه افق محدود
$$\min_{\mathbf{U}} \quad J = \sum_{k=0}^{N-1} \left( \|\mathbf{x}_k - \mathbf{x}_{k,\text{ref}}\|_{\mathbf{Q}}^2 + \|\mathbf{u}_k\|_{\mathbf{R}}^2 + \sum_{j=1}^M B_j(\mathbf{x}_k) \right) + \|\mathbf{x}_N - \mathbf{x}_{N,\text{ref}}\|_{\mathbf{Q}_f}^2$$

### تابع مانع نرم فرار از مانع
برای مانعی با مرکز $(x_{\text{obs}}, y_{\text{obs}})$ و فاصله ایمن $r_{\text{safe}}$:
$$d_k = \sqrt{(x_k - x_{\text{obs}})^2 + (y_k - y_{\text{obs}})^2}, \quad B(d_k) = \frac{\gamma}{(d_k - r_{\text{safe}})^2}$$

## 🚀 راهنمای نصب و اجرای سریع

```bash
# کلون مخزن
git clone https://github.com/ArdavanGhal-Eh/amr-trajectory-nmpc-cpp.git
cd amr-trajectory-nmpc-cpp

# بیلد بهینه
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

# اجرای شبیه‌سازی حلقه بسته
./build/nmpc_controller

# مصورسازی مسیر حرکت و عبور از مانع
cd python_visualizer
pip install -r requirements.txt
python plot_nmpc_trajectory.py
```
